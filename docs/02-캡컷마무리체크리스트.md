# 02. 캡컷 마무리 체크리스트

지시서와 자막을 만든 뒤 **사람이 하는 구간**. 스킬이 작업 폴더에 `캡컷체크리스트.md` 로 복사해 경로를 채워 준다.
승인함 카드에도 같은 6단계가 체크박스로 들어간다.

## 원칙

- 캡컷에는 **원본 회차 통째가 아니라 `미리보기.mp4`(컷만 이은 것)** 를 넣는다. 원본 풀 클립을 올려 수작업으로 자르면 느리고 디스크가 찬다.
- 최종 컷은 사람이 캡컷에서 미세 조정한다. 자동 받아쓰기 시각은 ±0.5초 어긋날 수 있다(P8-2).

## 파일 경로 (스킬이 채움)

```
영상:   <폴더>/미리보기.mp4
자막:   <폴더>/자막.srt
나레이션: <폴더>/나레이션.txt
지시서: <폴더>/편집지시서.md
```

## 6단계

- [ ] **1. 미리보기 불러오기** — `미리보기.mp4`. 컷이 이미 이어 붙은 상태.
- [ ] **2. 캔버스 9:16 + 얼굴 중심 확대** — 지시서 `화면 메모`의 얼굴 위치(좌/우/중앙)를 크롭 기준으로.
- [ ] **3. `자막.srt` 불러오기** — 타임라인 기준으로 이미 계산됨. 강조 단어(지시서 `소리 메모`)만 키운다.
- [ ] **3-1. 민감 처리 확인** — 지시서 `민감 처리` 표를 보며: 우회 컷의 대체 화면에 말하는 입이 없는지, 음성과 화면이 어긋나지 않는지, 민감한 소리의 음량·삐·0.1~0.2초 페이드를 적용했는지(S11). 가림(블러·모자이크)이 지정된 구간은 여기서 입힌다.
- [ ] **4. 나레이션 TTS** — `나레이션.txt` 로 생성해 나레이션 컷에 배치. 문장별 권장 길이(글자 수 ÷ 7)에 맞춰 속도 조절.
- [ ] **5. 제목 텍스트 삽입** — 지시서에서 고른 두 줄 제목.
- [ ] **6. 내보내기 → 보관함에서 검수·승인**

보조: ⚠ 표시된 `확인 필요 경계` 컷은 소리를 들으며 맞춘다. 욕 삐 처리(C5-12). BGM은 대사 구간에서 낮춘다(C10-2).

## 시각 오차 기록 (작업마다 입력)

| 항목 | 값 |
|---|---|
| 보정한 컷 수 | |
| 가장 크게 보정한 값(초) | |
| 보정 방향 | 앞으로 / 뒤로 / 섞임 |
| 총 소요 시간(분) | |
| 메모(어느 컷, 왜) | |

이 값이 쌓이면 P8-3 의 여유값(첫 음절 0.1초 전 / 끝 0.2초 후)과 P8-2 의 ±0.5초 가정을 **데이터로 고친다.**

## 디스크 공간 대응

| 대응 | 효과 |
|---|---|
| ffmpeg가 필요한 구간만 `cuts/` 로 미리 잘라 저장 | 캡컷에 불러오는 용량 대폭 감소 |
| 작업 완료 후 캡컷 캐시·임시 파일 정리 | 반복 제작 시 누적 방지 |
| 원본 폴더는 용량 큰 드라이브, 프로젝트·캐시는 다른 드라이브 | 시스템 드라이브 가득 참 방지 |
| 제작 서버: 여유 N GB 미만이면 새 작업 보류(`blocked_disk`) | 중간 실패 방지 |

## 캡컷 자동화에 대하여

캡컷 프로젝트 파일을 직접 생성하는 방법이 있으나 **비공식 구조**라 버전 업데이트로 깨질 위험이 크다. 초기에는 수동 마무리 + 미리보기 영상으로 간다. 효과가 확인되면 세로 변환·자막 번인·제목을 ffmpeg로 자체 렌더하는 쪽을 검토한다(캡컷 의존 제거 → SaaS화 쉬움).
