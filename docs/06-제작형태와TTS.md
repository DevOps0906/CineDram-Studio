# 06. 제작 형태 2가지 · 상하 템플릿 · TTS 단계

엔진: `engine/shortsflow.py` (Python 3.11 표준 라이브러리 + ffmpeg/ffprobe). 기준 파일은 **`컷표.json`** 하나다.
규칙: `rules/common.md` §10-2 (A10-x). 샘플: `engine/examples/make_sample.py`.
사용자 명칭(2026-11-02): **제작 모드** 3가지 = 자동제작(A) · 캡컷으로 편집(B) · Aside 사용하기(C, 외부 AI 브라우저 앱 — docs/08 §1). 원클릭 폼 기본값은 **자동제작**(사용자 확정, [docs/13 §16](13-원클릭제작흐름.md)). 아래 "처음 몇 편은 B 권장"은 권고로만 남는다.

## 순서 (두 형태 공통)

```
컷표.json 작성(스킬, meta.plan 포함) → check → tts-plan → (TTS 도구로 비트별 mp3) → tts-measure → recalc → **approve(사람, 기획 확정)** → 형태 선택
```

| 명령 | 하는 일 |
|---|---|
| `check` | 규칙 위반 검사(총 길이, 끝 나레이션, 민감 장면 위치, 우회 화면, 자막 길이·속도, 간격) |
| `tts-plan` | `나레이션.md`, `tts/TTS_줄.txt` 생성 + 텍스트 확정 점검(속어·미확정·숫자) |
| `tts-measure` | `tts/NN_이름.mp3` 실제 길이 측정 → `tts_clips.json`, 초당 글자 수 산출 |
| `recalc` | 나레이션 컷 = 실측 + 0.2초, 타임라인·`자막.srt`·`편집지시서_표.md` 재계산 |
| `approve` | **기획 선행 게이트(P0)**: 기획 항목 검사 + 사람 승인 기록(`기획승인.json`, `기획서.md`). 승인 없이, 또는 승인 뒤 컷표가 바뀌면 아래 3개가 거부된다 |
| `render` | **형태 A** 자동화 |
| `handoff` | **형태 B** 캡컷 넘기기 |

## 형태 A — 자동화 (`render`)
상하 템플릿 완성 영상 `숏폼_상하템플릿.mp4`(1080x1920)까지 자동 생성. 컷, 원음 낮춤(15%), TTS 믹스, 자막·제목 번인.
사람은 **영상 확인과 승인**만 한다. 민감 우회·페이드(0.1초)도 반영된다. 업로드는 하지 않는다.

## 형태 C — AI 어시스턴트 위임 (`delegate`)
`위임패키지/위임프롬프트.md`(컷 표·템플릿·금지 블록 포함) + `자막.srt` + `tts/` + `방식비교기록.json`. 결과는 매번 달라 **사람 검수 필수**. 상세는 docs/08 §1.

## 형태 B — 캡컷 넘기기 (`handoff`)
`캡컷패키지/`: `cuts/NN.mp4`(길이·간격 확정, TTS 미포함), `tts/`(번호 파일), `자막.srt`, `미리보기.mp4`(TTS 포함 참고용), `캡컷체크리스트.md`(상하 템플릿 좌표, 나레이션 배치표, 시각 오차 기록).

| 고르는 기준 | A 자동화 | B 캡컷 |
|---|---|---|
| 속도·대량 | ✓ | |
| 세밀한 연출·효과 | | ✓ |
| 처음 몇 편(품질 확인) | | ✓ 권장 |

## 상하 템플릿 (`engine/templates/topbottom.json`)
캔버스 1080x1920. 위 0~480 제목(두 줄, 파란 선), 가운데 y480 영상 1080x608, 아래 자막(중심 y1300, 앱 UI 안전 영역 회피), 하단 채널명. 값은 JSON에서 바꾼다.

## 검증 결과 (2026-11-02)
합성 샘플(가짜 원본·SRT·톤)로 `tts-plan → tts-measure → render → handoff` 실행: `render` 1080x1920 31.8초 영상+오디오, `handoff` 컷 7개·미리보기·체크리스트 생성 확인. **실제 영상·실제 TTS(MiniMax)로는 아직 검증하지 않았다.**

## 미구현·주의
- MiniMax API 자동 호출 없음(수동으로 mp3 생성 후 `tts-measure`). 약관·AI 표시는 사용자 확인(A10-10).
- 컷표.json은 아직 스킬이 자동 생성하지 않는다(SKILL.md 6-1에 작성 절차는 반영함).
- **얼굴 자동 검출·화자 판정은 미구현**이다(컷별 `face{x,y,h}` 수동 입력). 자동화(OpenCV 등)는 후속.
- 후킹타임형 템플릿 좌표는 썸네일 비율 추정이다(docs/07). 레이아웃 PNG로 보정 필요.
- 렌더 미확인: 실제 한글 자막 외곽선·위치 육안 확인, 단위 테스트 미작성.
