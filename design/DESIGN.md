- 정답 소스: `design/tokens.css` (Tailwind CSS v4.3.3 `@theme`, 라이트/다크 두 벌, `.dark` 전환). 이 문서와 코드가 다르면 코드가 이긴다.

- 근거: 화면·구간·폰트·권리 규칙 `docs/03-화면설계.md`, 구축 규칙 `nomad-design-modules/_design-guide/DESIGN_SYSTEM.md` §2·3·4·6·7, 절차 `DESIGN_PRINCIPLES.md` 7단계, 패턴 코드 `DASHBOARD_PATTERNS.md` §2.

## 1. 레퍼런스와 방향

| 구분 | 레퍼런스 | 가져올 것 | 뺄 것 |
|---|---|---|---|
| 주 | Atlassian Design System | 상태 배지 = 옅은 바탕 + 진한 글자 + 아이콘 + 텍스트(색만으로 표시하지 않음), 워크플로 단계 표시, 승인/보류처럼 결과가 갈리는 버튼의 위계(주 1개 + 보조 + 텍스트형) | 브랜드 색·로고·일러스트·카피, 둥근 아바타 장식, 보드 전체를 똑같은 카드로 쪼개는 구성 |

## 2. 토큰 역할 (값은 `DESIGN_TOKENS.md`)

| 역할 | 토큰 | 비고 |
|---|---|---|
| 바탕 / 패널 | `--color-bg` / `--color-surface` | 카드는 surface + `--color-border`, 그림자는 `--shadow-card`(거의 없음) |
| 글자 / 보조 글자 | `--color-text` / `--color-text-muted` | 대비 검사 통과(라이트·다크 모두 4.5:1 이상) |
| 입력 경계 · 진행바 미완 | `--color-input` | 3:1 이상 (WCAG 1.4.11) |
| 포커스 링 | `--color-focus` | 2px 실선 + 2px 오프셋, `:focus-visible`만 |
| 주 행동 | `--color-primary` / `-fg` | 승인 · 실행 · 선택 확정 |
| 강한 CTA | `--color-strong` / `-fg` | 벤치마크 검정 버튼 변형 — 순검정 대신 본문색 |
| 비활성 | `--color-disabled` / `-fg` | "준비 중" 같은 회색 버튼 |
| 위험 행동 | `--color-danger` / `-fg` | 취소(확인 모달 안에서만 solid) |
| 완료 | `--color-success` / `-fg` | 진행바 완료 단계 |
| 칩·배지 5톤 | `--color-{info,success,neutral,danger,warning}-subtle` / `-fg` | 3.2 표, info는 링크 버튼·사이드바 선택에도 |
| 글자 크기 | `--text-page-title` · `--text-card-title` · `--text-body` · `--text-label` · `--text-score` | docs/03 폰트 토큰 + 점수 숫자, 모두 3구간 |
| 높이 | `--size-touch`(44) · `--size-control`(36) · `--size-pill`(28) · `--size-chip`(20) · `--size-row` · `--size-row-compact` | 36·28·20은 시각 높이, 탭 영역은 항상 44 이상 |
| 레이아웃 | `--size-sidebar` · `--size-tabbar` | 데스크톱 1200~ 전용 |
| 반경 | `--radius-badge` < `--radius-control` < `--radius-card` < `--radius-sheet`, `--radius-pill` | 위계별로 다르게(생성형 기본값 4번 회피) |
| 그림자 | `--shadow-card` · `--shadow-overlay` | 떠 있는 층(토스트·드로어·시트·모달)만 overlay |

3구간 폰트 표(자동 생성): `design/DESIGN_TOKENS.md` "글자 크기 (반응형 3구간)".
| 모션 | `--duration-fast` · `--duration-base` · `--ease-standard` | `prefers-reduced-motion`에서 0ms |

서체: `--font-sans` = Pretendard 한 가족(본문·제목·숫자). 숫자·경과 시간·점검 개수는 Tailwind `tabular-nums` 유틸리티로 정렬하고, 모노스페이스는 쓰지 않는다.

## 3. 컴포넌트 · 배리언트

컴포넌트는 shadcn/ui(Tailwind v4 지원판)를 저장소에 복사해 위 토큰으로 재스타일한다. 아이콘은 Lucide SVG만(이모지 금지). 모든 상태: 기본 · 호버 · 포커스 · 비활성 · 오류 · 로딩.

### 3.1 버튼

| 배리언트 | 바탕 / 글자 | 높이 | 반경 | 쓰는 곳 |
|---|---|---|---|---|
| primary | `primary` / `primary-fg` | `--size-touch` | `--radius-control` | 승인, 실행, 이 소재로 진행 |
| secondary | `surface` + `--color-input` 경계 / `text` | `--size-touch` | `--radius-control` | 수정 요청, 다시 만들기, 영상 확인, 보관 |
| strong | `strong` / `strong-fg` | `--size-touch` | `--radius-control` | 만들기 화면의 [실행] (카드 그리드 안 주 행동) |
| link-sm | `info-subtle` / `info-subtle-fg` | 시각 `--size-control`, 탭 영역 `--size-touch` | `--radius-control` | 카드 안 보조 진입("이 소재로 만들기" 류) |
| ghost | 투명 / `text-muted` | `--size-touch` | `--radius-control` | 취소(카드 안), 자세히 펼치기 |
| danger | `danger` / `danger-fg` | `--size-touch` | `--radius-control` | 취소 확인 모달의 최종 버튼만 |
| disabled | `disabled` / `disabled-fg` | 원래 크기 유지 | 원래 반경 | 모든 배리언트의 비활성 — `aria-disabled` + 이유 툴팁 |

- 한 카드·한 화면에 primary(또는 strong)는 1개. 비활성은 `opacity` 대신 `disabled` 토큰(대비 확보).

### 3.1.1 필터 필 · 토스트 · 탭바 (벤치마크 유래)

| 컴포넌트 | 배리언트 | 토큰 |
|---|---|---|
| 필터 필 | 선택 / 비선택 / 포커스 | `primary`·`primary-fg` / `neutral-subtle`·`-fg` / `--color-focus` 링, 높이 `--size-pill`, `--radius-pill`, `--text-label` 600 |
| 토스트 | 정보 / 오류 | 우하단, `surface` + `--color-border` + `--shadow-overlay`, `--radius-pill`, `--text-label` / 오류는 `danger-subtle`, `aria-live="polite"` |
| 탭바(데스크톱) | 열린 탭 / 활성 탭 | `surface` / `bg` + 하단 2px `primary`, 높이 `--size-tabbar` |
| 사이드바 항목 | 기본 / 선택 / 대기 개수 배지 | `text-muted` / `info-subtle`·`-fg` / `neutral-subtle` 칩, 높이 `--size-row-compact` |

### 3.2 상태 배지 5종 (색 + 아이콘 + 텍스트 — 셋 다 필수)

| 상태 | 텍스트 | Lucide 아이콘 | 바탕 / 글자 토큰 | 의미 |
|---|---|---|---|---|
| 제작 가능 | 제작 가능 | `circle-check` | `success-subtle` / `success-subtle-fg` | 원본·권리·디스크 모두 충족 |
| 업로드 검토 필요 | 업로드 검토 필요 | `scan-eye` | `info-subtle` / `info-subtle-fg` | 사람 승인 대기 |
| 원본 없음 | 원본 없음 | `file-x` | `neutral-subtle` / `neutral-subtle-fg` | 원본 들어오면 자동 제작 대기 |
| 권리 미확인 | 권리 미확인 | `shield-alert` | `danger-subtle` / `danger-subtle-fg` | 업로드 경로 차단(R9-1) |
| 디스크 부족 | 디스크 부족 | `hard-drive` | `warning-subtle` / `warning-subtle-fg` | 제작 일시 정지 |

- 공통: 최소 높이 `--size-chip`, 좌우 패딩 `spacing×2`, `--radius-badge`, 글자 `--text-label` 굵기 600, 아이콘 1em. 한국어 긴 라벨은 줄바꿈 허용(잘라내지 않음).
- 구성 배지(7종 규칙 파일에서 옴, 예: 한드짜)는 상태 배지와 구분해 `neutral-subtle` + 아이콘 없음 + 굵기 500.

### 3.3 승인 카드 (승인함 · 모바일 기준, docs/03 "승인함 카드")

| 영역 | 내용 | 토큰 |
|---|---|---|
| 머리줄 | 구성 배지 · 작품명 · 회차 · 경과 시간(우측, `tabular-nums`) | `--text-label`, `text-muted` |
| 제목 | 두 줄까지, 넘치면 말줄임 + 전체는 펼침 | `--text-card-title` 굵기 600 |
| 영상 확인 | 썸네일(9:16) + "영상 확인" 버튼 | secondary, `--size-touch` |
| 점검 줄 | ✓통과 △경고 ✗실패 개수, ⚠경계 개수 — 기호는 Lucide `check`·`triangle-alert`·`x` + 숫자 + 텍스트 라벨 | `--text-label` |
| 체크 6칸 | 사람 확인 항목(캡컷 편집 여부 등) — 체크박스 44×44 터치 영역 | `--color-input` 경계 |
| 결정 줄 | [승인] [수정 요청] [다시 만들기] + 카드 우상단 ⋯ 메뉴에 취소 | primary 1 + secondary 2 |

| 배리언트 | 결정 줄 | 업로드 예약 |
|---|---|---|
| 일반(승인 대기) | 승인 · 수정 요청 · 다시 만들기 | 비활성 |
| 권리 미확인 | **[승인] 대신 [보관]**(secondary), 카드 머리에 권리 미확인 배지 고정 | 표시하지 않음(R9-1) |
| 승인됨 + `rights_status ∈ {own, licensed}` | 승인 완료 표시 + 승인 로그(누가·언제·점검 결과) | **활성**(primary) |
| 점검 실패(✗ ≥ 1) | 승인 버튼 비활성 + 이유 툴팁, 수정 요청이 첫 버튼 | 비활성 |
| 처리 중(로딩) | 누른 버튼에 스피너, 나머지 비활성 | — |

- 모바일: 1열 카드, 결정 줄은 카드 하단 가로 3분할(각 최소 44 높이). 태블릿·데스크톱: 목록 + 우측 상세(같은 카드 구성).

### 3.4 진행바 5단계 (제작 현황)

| 단계 | 소재 → 원본 → 제작 → 검수 → 업로드 |
|---|---|
| 완료 | `--color-success` 칸 + `check` 아이콘 + 단계명 |
| 진행 중 | `--color-primary` 칸 + 단계명 굵게 + 경과 시간 |
| 대기 | `--color-input` 칸(3:1) + 단계명 `text-muted` |
| 막힘 | 칸은 대기색, 단계명 옆에 해당 상태 배지(원본 없음·권리 미확인·디스크 부족) |

- 두께 `--size-progress`, 칸 사이 간격 `spacing×1`. 단계명은 모바일에서 진행 중 단계만 표시, 태블릿 이상 5개 모두 표시. `role="list"` + 각 칸 `aria-current="step"`.
