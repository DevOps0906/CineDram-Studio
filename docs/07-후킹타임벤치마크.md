# 07. 후킹타임 벤치마크 (템플릿 구조)

관찰일 2026-11-02. 대상: 유튜브 채널 `@후킹타임` Shorts 탭(브라우저로 열어 목록과 썸네일 확인).
**관찰한 것과 추정한 것을 구분한다.** 영상 본편을 재생해 보지는 않았고, 썸네일(=영상 프레임)과 제목·조회수만 근거다.

## 1. 채널 개요 (화면 표시)

| 항목 | 관찰값 | 비고 |
|---|---|---|
| 구독자 / 영상 수 | 5.17만 / 208개 | 채널 헤더 |
| "영상 수익 창출 X" | 헤더에 표시 | 확장 프로그램(vidIQ) 오버레이로 보임. 정확성 **미확인**. 사용자가 전달한 스튜디오 수익 자료와 상충하므로 스튜디오 값을 우선한다 |
| 소재 작품 | 화면에 보인 최신 약 50편이 전부 **한 드라마**(일타 스캔들) | 작품 집중 → 리스크(docs/08) |
| 조회수 분포 | 최저 3만대 ~ 최고 194만 | 상위: 194만 · 184만 · 176만 · 157만 · 133만 · 131만 |

## 2. 영상 레이아웃 (썸네일 관찰 → `engine/templates/hookingtime.json`)

| 영역 | 관찰 | 템플릿 값 |
|---|---|---|
| 캔버스 | **순수 검정** 배경 | 1080x1920, 검정 |
| 상단 | 제목 **2줄**, 굵은 고딕, 1줄 노랑 · 2줄 빨강 | y 0~340, 중심 y175, 92px |
| 중앙 | 영상이 창을 **꽉 채우고 말하는 얼굴이 중앙**. 창은 가로로 약간 긴 사각형(거의 정사각에 가까움)으로 보임 | y340, 1080x1090, `cover`, 얼굴 높이 34%, 얼굴 세로 위치 42% |
| 중앙 하단 | 영상 안 **자막**, 굵은 외곽선, 주로 빨강(일부 흰색) | 중심 y1290, 70px, 빨강 + 검정 외곽선 |
| 상황 캡션 | 영상 안 위쪽에 `(아빠 소환)` 같은 괄호 캡션이 가끔 | 템플릿 미포함(캡컷에서 추가) |
| 하단 | 검은 띠에 이탤릭 흰 글씨 **`드라마 <일타 스캔들>`** | 중심 y1620, 이탤릭, `meta.source_caption` |

- **추정:** 썸네일은 목록에서 잘려 보여 정확한 비율을 알 수 없다. 위 좌표는 비율 추정이며 **실제 영상(또는 프레임 PNG)으로 보정**해야 한다. 정확한 프레임 사양은 사용자가 보관 중인 레이아웃 PNG 로 확정한다.
- 색(노랑 `FFE600`, 빨강 `FF2A2A`)은 육안 근사값이다.
- 하단 "핵심 대사 박스"는 사용자 전달 자료(v8.1)에서 확인된 요소이며 이번 관찰에서는 보지 못했다 → docs/08 §4.

## 3. 제목 패턴 (실제 제목 약 50개 관찰)

| 패턴 | 예(원문) | 빈도 |
|---|---|---|
| `[역할]+[행동] + ~의 최후` | 흙수저 전교 1등 쫓아낸 대치동 맘충의 최후 | 가장 많음(약 10) |
| `[역할]+[행동] + ~하면 생기는 일` | 변호사 엄마한테 반말 까면 생기는 일 | 약 5 |
| `[역할]+[행동] + ~의 한마디/한 말` | 엄마 스캔들로 놀린 친구 옆자리 남학생의 한마디 | 약 5 |
| `~한 이유 / 정체 / 과거` | 일타강사가 조교 시절 잘린 진짜 이유 | 약 5 |
| 그 밖 | 변호사 엄마가 한 짓, ~하는 법, ~이 치른 대가 | — |

- **극 중 이름을 쓰지 않고 역할·신분으로**(변호사 엄마, 일타강사, 대치맘, 흙수저, 일진, 학원 원장, 전학생). 규칙 C4-4와 일치.
- 결과는 숨기고 결과의 **종류**만 말한다(최후, 한마디, 대가). 규칙 C4-1과 일치.
- 길이: 두 줄, 줄당 7~12자, 전체 15~22자(공백 제외). 규칙 C4-3의 기준표 안.
- 기호: `ㅋㅋ`, `ㄷㄷ` 붙인 제목이 일부 있음, 욕은 `쓰X기`로 가림(C5-12와 일치). 해시태그는 제목에 없음.
- 조회수 상위 제목은 **구체적 역할 + 긴장 관계**가 명확한 것(하필 변호사 엄마를 건드린 대치맘 대장 194만, 일타강사 일정 멋대로 바꾼 원장이 치른 대가 176만).
- 제목 꼬리별 성과 비교는 표본 한 번의 목록 관찰로는 결론내지 않는다 → 성과 테이블에서 측정(docs/08).

## 4. 우리 시스템 반영

| 벤치마크 관찰 | 반영 |
|---|---|
| 상하 템플릿 + 얼굴 중심 꽉 채움 | `hookingtime.json`, `video.fit=cover`, 컷별 `face{x,y,h}` → `crop_plan()` (v6.1 규칙: 기본 → 얼굴 크기 → 중앙 보정 → 상한 1.5) |
| 제목 2줄 색 분리 | `title.colors` (ASS 줄별 색) |
| 하단 `드라마 <작품>` | `meta.source_caption` (출처 표기는 **사용 허락이 아니다**, R9-1 과 별개) |
| 영상 안 자막 위치 | `subtitle.center_y` |
| 제목 꼬리 4종 | `rules/channel-hookingtime.md` |
| 단일 작품 집중 | 작품 비중 경고(docs/08) |

## 5. 렌더 검증 (합성 샘플)
`render --template hookingtime` 결과: 1줄 노랑 · 2줄 빨강 제목, 얼굴 좌표 기준 꽉 채움 크롭, 영상 안 빨간 자막, 하단 출처 띠 확인. 얼굴 좌표는 **수동 입력**(자동 검출은 미구현).
