# 04. 로드맵과 리스크

## 로드맵 (린 검증 순서)

스킬의 품질이 곧 제품의 품질이다. **UI 전에 규칙이 쓸 만한 결과를 내는지 먼저** 본다.

| 단계 | 기간 | 내용 | 검증 기준 |
|---|---|---|---|
| 0 | 3~5일 | 스킬+규칙만으로 1편. 본인 채널 영상(역사 다큐)으로 `own-content` | 캡컷 컷 오차(초), 소요 시간, 디스크 사용량 |
| 1 | 1~2주 | 상태머신 + 로컬 SQLite + 만들기 화면 1개(작품·원본 직접 선택) | 클릭 3번으로 지시서 생성 |
| 2 | 2주 | 링크 입력 + 작품 매칭 신뢰도 + 원본 폴더 감시 | 매칭 정확도, 원본 도착 시 자동 시작 |
| 3 | 2주 | 제작 현황 패널 + 승인함 | 승인 대기에서 5분 안에 처리되나 |
| 4 | 2~3주 | 제작 기록 DB, 결 태그, 소재 모드 3종 | 같은 작품 5편이 서로 안 겹치나 |
| 5 | 3~4주 | 레이더(진입 성적표, 떡상쇼츠, 황금키워드) — 모듈 3종 상세는 `docs/12` | 추천 소재가 실제로 더 잘 나오나(`topics.radar_ref` 로 사용/미사용 타율 비교) |
| 6 | 이후 | 업로드 예약 연동, 다채널, SaaS화 | — |

링크 입력은 레이더보다 먼저다. 잘 된 쇼츠를 붙여 넣는 것이 가장 쉬운 소재 입력이기 때문이다.

### 단계 0 상세 — 해 볼 것

1. 본인 보유 영상 1편 + SRT(없으면 `faster-whisper`)로 `skills/shorts-blueprint/SKILL.md` 를 그대로 실행.
2. 지시서대로 캡컷에서 컷하며 **시각 오차를 측정**(`docs/02` 기록표).
3. 같은 영상으로 구성을 바꿔 한 번 더(예: `own-content` 대 `touching-reversal`) → 규칙 차이가 결과에 나는지 본다.
4. 쇼츠 3편 정도를 올려 조회수·완주율로 규칙 효과를 본다. **업로드는 사람이 직접.**
5. 효과가 확인되면 규칙을 채널용으로 포크한다.

### 단계 0 통과 기준 (제안)

| 지표 | 통과선 |
|---|---|
| 컷 경계 보정이 필요한 컷 비율 | 30% 이하 |
| 최대 보정 | 0.5초 이하 |
| 점검표 ✗ 잔존 | 0 |
| 1편 총 소요(캡컷 포함) | 사용자가 정한 목표 이내 |

통과선은 첫 측정 후 사용자가 조정한다. 임의 숫자이며 근거 데이터가 아직 없다.

## 기술 선택

| 항목 | 선택 |
|---|---|
| 실행 주체 | A. 데스크탑 수동 → B. Claude Code 헤드리스. C. API 직접 호출은 SaaS 단계 |
| 대시보드 | Next.js + Supabase, 단계 1은 SQLite |
| 받아쓰기 | faster-whisper 로컬 (GPU 있으면 medium 이상) |
| 영상 처리 | ffmpeg (미리보기 컷은 재인코딩, 최종은 캡컷) |
| 갱신 | 3초 폴링 → SSE/Realtime |
| 레이더 데이터 | 공식 API 우선(YouTube Data API), 시즌오픈은 수동 입력으로 시작. 스크래핑은 피한다 |

## 리스크

| 리스크 | 설명 | 대응 |
|---|---|---|
| **원본 영상 자르기의 저작권·수익화** | 콘텐츠 ID 클레임, 수익 몰수, 채널 경고·폐쇄, "재사용 콘텐츠" 분류. **나레이션을 얹는 것만으로 면책되지 않는다** | `own-content` 를 1순위 구성으로. `sources.rights_status` 로 `unverified` 는 업로드 차단. 외부 작품 모드는 별도 경고와 분리 |
| **링크 → 작품 → 원본** | 남의 쇼츠를 보고 같은 장면을 원본에서 다시 뽑는 흐름. 원본 확보 경로와 권리는 사용자 책임 | 링크는 분석 전용(R9-2). 제품 기본값은 자체 보유·라이선스 소스 |
| **자동 업로드** | 반복·대량 생산 콘텐츠 정책에 걸리면 채널 전체가 위험 | 기본 꺼짐, 검수 후 승인 기본, 승인 로그 보관 |
| **남의 유튜브 영상 내려받기** | 이용약관상 허용되지 않고 업로드 시 클레임 위험 | `external_youtube` 는 `unverified` 기본. 본인 영상은 스튜디오에서 내려받기 |
| **중복 소재** | "같은 소재" 반복 시 유사 영상 누적 | topics 사용 여부 + 결 태그 + 구간 겹침 40% 상한 |
| **받아쓰기 오류** | 인명·고유명사, 구간 시각 ±0.2~0.5초 | 교정 기록(P8-5), 확인 필요 경계(P8-2~4), 캡컷 보정량 데이터화 |
| **디스크 부족** | 1080p 원본 다회차 | `blocked_disk` 상태, `cuts/` 선절단, 드라이브 분리 |
| **레이더 데이터** | 조회수·떡상 스크래핑은 불안정 | 공식 API + 수동 입력 병행 |

## 사업 확장 (검증 뒤)

- **SceneFlow 연동:** 이 구조의 "컷 설계 + 자막 재계산 + 점검표"를 SceneFlow 설계 모듈로. 별도 제품이 필요 없다.
- **규칙팩 판매:** 구성 7종이 곧 상품 라인업. 역사 다큐용, 쇼핑 쇼츠용, 강의 하이라이트용 규칙팩을 판매/구독.
- **승인함(모바일):** 자는 동안 만든 영상을 아침에 폰으로 승인. 이 화면만 따로 팔 수도 있다.
- **강의/전자책:** "Claude 스킬로 쇼츠 공장 만들기".
- **원본 폴더 감시 + 자막 자동 생성:** 파일만 넣어 두면 지시서가 쌓이는 시스템. 자체 콘텐츠에 그대로 적용.
