# 채널 스타일: 후킹타임형 (channel-hookingtime.md)

구성 규칙(`drama.md` 등) **위에 얹는 선택 층**이다. 공통·구성 규칙을 대체하지 않고 **옵션**을 켠다. 효과는 A/B 로 확정한다(docs/08).
근거: `docs/07-후킹타임벤치마크.md` (2026-11-02 관찰). 로드: `common.md` + 구성 파일 + 이 파일. 템플릿: `engine/templates/hookingtime.json`.

## 제목 꼬리 6종

제목 = `[역할] + [행동] + {꼬리}`. 작품·직업 키워드(예: 일타강사)를 넣는 패턴이 있어 `황금키워드` 로 따로 기록한다(docs/10). 꼬리는 작업마다 하나를 고르고 `planning_points` 에 기록한다.

| 꼬리 | 쓰는 때 | 끝 3초 조건(C4-2) |
|---|---|---|
| `~의 최후` | 가해 쪽이 무너지는 결말 | 당한 쪽의 굳은·무너진 얼굴 |
| `~하면 생기는 일` | 상황이 뒤집히는 결말 | 뒤집힘 직후 반응 |
| `~의 한마디` / `~한 말` | 받아치는 대사가 펀치 | 펀치 끝음절 + 반응 |
| `~한 이유` / `정체` / `과거` | 숨은 사실이 드러나는 결말 | 사실이 드러나는 장면 |
| `~한 진짜 이유` | 알려진 이유와 실제가 다른 결말 | 진짜 이유가 드러나는 장면 |
| `~한 대장` / `~의 대장` | 가해 무리의 우두머리가 당하는 결말 | 우두머리의 반응 얼굴 |

## 옵션 (기본값은 공통 규칙, 켜면 덮어씀)

| 옵션 | 기본 | 켜면 | 근거 |
|---|---|---|---|
| **S-1** 제목 끝 `ㅋㅋ`/`ㄷㄷ` | 끔(C4-5) | 허용. 한 소재에 있음/없음 2종 A/B | 상위 일부 영상에서 관찰 |
| **S-2** 영상 안 괄호 캡션(`(아빠 소환)`) | 끔 | 상황 설명 한 줄. 지시서 `화면 메모`에 적고 캡컷에서 입힘 | 일부 영상에서 관찰 |
| **S-3** 첫 자막을 상황 설명으로 시작 | 끔(C3-2) | 전달 자료에 있는 사례. 후킹 대사를 1컷 뒤로 미루지 않는다(첫 소리는 여전히 0초) | 전달 자료 |
| **S-4** 해시태그 | 끔 | 영상 하단 작품 해시태그. 제목에는 쓰지 않는다 | 전달 자료 |
| **S-5** 하단 출처 띠 `드라마 <작품>` | 켬 | `meta.source_caption`. **허락이 아님**을 지시서에 병기 | 관찰 |

## 레이아웃 약속 (`hookingtime`)

- 제목 두 줄, 1줄 노랑 · 2줄 빨강(둘째 줄을 흰색으로 바꿔 A/B 가능).
- 가운데 영상은 **빈 곳 없이 채우고 말하는 얼굴을 중앙에**(컷별 `face{x,y,h}`). 확대 상한 1.5(1080p 원본), 상한 도달 컷은 경고 → 구도를 사람이 확인.
- 이어지는 같은 인물 컷은 확대율 차이를 ±10% 이내로(어지럼 방지, SHOULD).
- 나레이션 컷·반응 컷의 화자 판정은 `화면 메모`의 **역할**로 지정(이름 금지). 반응 컷은 말하는 사람이 아니라 **당한 사람**을 중앙에(C6-2).
