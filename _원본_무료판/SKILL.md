# 영드짜 AI 설계도

영화 한 편이나 드라마 한 회차에서 **시청자가 끝까지 보는 쇼츠 한 편**을 설계한다.
편집은 사람이 캡컷에서 하고, 이 스킬은 "어디를, 어떤 순서로, 무슨 말을 붙여 자를지"를 원본 시각까지 정확히 정해 준다.

판단 기준은 모두 같은 폴더의 `규칙.md` 에 있다. **단계에 들어가기 전에 해당 절을 연다.**

## 0. 시작 전에 확인

1. **원본 영상 경로**를 받고, 같은 폴더에 **같은 회차 자막 파일(SRT)** 이 있는지 본다.
   - 자막이 없으면 아래 「0-1. 자막 만들기」로 간다. 자막 없이 대사 시각을 짐작해서 진행하지 않는다.
2. 여러 회차를 주면 회차마다 자막을 따로 받는다(회차 섞기형이 가능해진다).
3. 결과는 원본 옆에 `쇼츠_<작품>_<회차>` 폴더를 만들어 저장한다.

## 0-1. 자막 만들기 (자막 파일이 없을 때)

사용자에게 두 방법을 보여 주고 고르게 한다.

**A. 캡컷·브루 같은 편집 프로그램의 자동 자막 (설치 없음)**
- 원본을 편집 프로그램에 넣고 자동 자막(음성 인식)을 돌린 뒤 **SRT로 내보내** 원본 옆에 저장해 달라고 안내한다.
- 메뉴 이름과 무료 한도는 프로그램·버전마다 다르니, 화면에서 '자막 내보내기 / SRT'를 찾으라고만 말한다.

**B. 이 PC에서 직접 받아쓰기 (클로드가 대신 실행)**
1. 파이썬이 있는지 본다(`python --version`). 없으면 설치부터 안내하고 멈춘다.
2. `pip install faster-whisper` 로 받아쓰기 도구를 설치한다.
3. 아래 내용으로 `받아쓰기.py` 를 만들어 실행한다. 그래픽카드(NVIDIA)가 있으면 `device="cuda"`, 없으면 `device="cpu"` 와 `model="small"` 로 바꾸고 "1시간짜리 회차면 30분 넘게 걸릴 수 있어요"라고 먼저 알린다.

```python
import sys
from faster_whisper import WhisperModel
src, out = sys.argv[1], sys.argv[2]
m = WhisperModel("medium", device="cuda", compute_type="float16")  # CPU면: WhisperModel("small", device="cpu", compute_type="int8")
segs, _ = m.transcribe(src, language="ko", vad_filter=True)
def t(s):
    h, r = divmod(s, 3600); mi, se = divmod(r, 60)
    return f"{int(h):02d}:{int(mi):02d}:{int(se):02d},{int(round((se % 1) * 1000)):03d}"
with open(out, "w", encoding="utf-8") as f:
    for i, s in enumerate(segs, 1):
        f.write(f"{i}\n{t(s.start)} --> {t(s.end)}\n{s.text.strip()}\n\n")
        print(i, t(s.start), s.text.strip(), flush=True)
```
   실행: `python 받아쓰기.py "<원본>" "<원본과 같은 이름>.srt"`
4. 받아쓰기는 사람 이름·고유명사가 틀릴 수 있다. 줄거리 파악에는 충분하지만, **자막 파일(5단계)을 만들 때는 틀린 글자를 문맥에 맞게 고친다.**

## 1. 줄거리 파악 (규칙 §1)

- 자막을 **처음부터 끝까지 다 읽는다.** 길면 나눠 읽되 건너뛰지 않는다. 앞부분만 보고 고르면 결말을 놓친다.
- 아래를 짧게 정리해 사용자에게 보여 준다.
  - 인물 관계: 이름 대신 **역할**로(예: 신입 검사, 부장, 전학생, 반장)
  - 이 회차의 갈등 목록: 누가 누구에게 무엇을 했나, 원본 시각과 함께

## 2. 소재 후보 3개 → 관문 ① (규칙 §1·§2)

후보마다 아래 표 한 줄을 채운다. 갈등이 화면·대사로 안 보이는 후보는 처음부터 넣지 않는다.

| 칸 | 쓰는 법 |
|---|---|
| 한 줄 요약 | 누가 누구에게 무엇을 당하고, 어떻게 뒤집히나 |
| 원본 구간 | 시작~끝 시각 (회차 섞기면 회차별로) |
| 기·승·전·결 킥 | 단계마다 시청자가 "헐/와/ㅋㅋ" 할 순간 하나씩, 원본 시각과 대사 |
| 끝 장면 | 마지막 대사·마지막 얼굴 |
| 방식 | 한 회차형 / 회차 섞기형 + 고른 이유 한 줄 |
| 약점 | 이 후보가 약한 이유가 있으면 솔직히 한 줄 |

→ **사용자에게 고르게 한다.** "알아서 해"라고 하면 킥이 가장 또렷하고 끝이 센 후보를 고르고 이유를 적는다.

## 3. 흐름 4줄 · 후킹 · 제목 → 관문 ② (규칙 §2·§3·§4)

1. **흐름 4줄**을 원본 시각과 함께 쓴다: ① 갈등 시작 ② 갈등이 세지는 근거 ③ 주인공의 대응·결과 ④ 결과 뒤 반응.
2. **후킹 시작점 2개**: 원본 시각 + 첫 대사 + 왜 궁금해지는지 한 줄.
3. **제목 후보 3개**: 두 줄, 결과는 숨기고 상황은 보이게. 각 제목 옆에 "이 제목이면 끝 장면은 OO" 를 적어 끝과 맞는지 보인다.

→ **사용자에게 고르거나 고치게 한다.**

## 4. 편집 지시서 (규칙 §5·§6)

`편집지시서.md` 에 컷 표를 쓴다. 원본 시각은 **자막 시각을 기준으로 소수 첫째 자리까지** 적는다.

| 번호 | 원본 시작 | 원본 끝 | 길이 | 들리는 것 | 화면 메모 |
|---|---|---|---|---|---|
| 1 | 12:03.4 | 12:05.1 | 1.7초 | (원음) "지금 뭐라고 했어?" | 말하는 사람 얼굴 크게 |
| 2 | 12:05.1 | 12:08.0 | 2.9초 | [나레이션 1] | 듣는 사람 표정 |

- 컷 1은 고른 후킹. 컷 2는 바로 나레이션.
- 나레이션 컷의 길이는 `글자 수 ÷ 7` 초로 잡고, 그 길이만큼 **대사 없는 원본 화면**(표정·반응)을 깐다.
- 대사 컷은 문장 첫 음절 0.1초 전에서 열고, 마지막 음절이 끝난 뒤 0.2초쯤에서 닫는다.
- 표 아래에 **총 길이**와 **끝 3초에 보이고 들리는 것**을 적는다.

`나레이션.txt` 에 나레이션 문장을 순서대로 적는다(번호는 컷 표와 같게).

## 5. 자막 파일 (규칙 §5)

`자막.srt` 를 **편집 뒤 타임라인 기준**으로 새로 만든다. 캡컷에 그대로 불러오면 된다.

- 컷 i 의 타임라인 시작 = 앞 컷 길이를 모두 더한 값.
- 원본 자막 한 줄이 컷 안에 있으면: 새 시작 = (원본 줄 시작 − 컷 원본 시작) + 컷 타임라인 시작. 끝도 같은 식.
- 컷 경계에서 잘리는 줄은 경계에서 자른다. 0.3초보다 짧아진 조각은 버린다.
- 나레이션 컷에는 나레이션 문장을 호흡 단위로 나눠 넣는다(그 컷 길이 안에서 고르게).
- 한 줄은 공백 빼고 14자 안팎. 넘으면 호흡이 끊기는 곳에서 두 줄 자막으로 나눈다.

## 6. 미리보기 영상 (선택)

사용자 PC에 `ffmpeg` 가 있으면(`ffmpeg -version` 으로 확인) 컷만 이어 붙인 미리보기를 만든다. 없으면 이 단계는 건너뛰고 "ffmpeg를 깔면 미리보기도 만들어 드려요"라고만 적는다.

1. 컷마다 잘라 `cuts/01.mp4` … 로 저장:
   `ffmpeg -y -ss <시작초> -to <끝초> -i "<원본>" -c:v libx264 -crf 20 -preset veryfast -c:a aac "cuts/01.mp4"`
2. `cuts/list.txt` 에 `file '01.mp4'` 를 순서대로 적고:
   `ffmpeg -y -f concat -safe 0 -i cuts/list.txt -c copy "미리보기.mp4"`
- 나레이션 컷은 소리가 비어 있다. 정상이다. TTS는 캡컷에서 입힌다.
- 세로(9:16) 맞추기·얼굴 확대·제목은 캡컷에서 한다.

## 7. 자가 점검 (규칙 §7)

`규칙.md` §7 점검표를 항목마다 ✓ / △ / ✗ 와 이유 한 줄로 채워 `편집지시서.md` 맨 아래에 붙인다.
✗ 가 있으면 고친 뒤 다시 점검한다. 고칠 수 없으면 사용자에게 그 이유를 말한다.

## 8. 마무리 보고

사용자에게 이 순서로 짧게 보고한다.
1. 고른 소재·제목 한 줄
2. 만든 파일 목록(경로)
3. 총 길이, 컷 수
4. 캡컷에서 할 일 3가지: 세로 맞추기·얼굴 확대 / 나레이션 TTS 입히기 / 제목 넣기

## 하지 않는 것

- 원작에 없는 결말·사과·처벌을 지어내지 않는다. 나레이션도 원작 사실만.
- 업로드, 채널 운영, 수익에 대한 약속을 하지 않는다.
- 저작권은 단정하지 않는다. 물으면 "작품과 플랫폼 정책마다 다르니 직접 확인하세요"라고 답한다.
