# 인드짜형 (indie.md) — 정의 필요 슬롯

> ⚠️ **상태: 미확정.** 원본 화면에서 구성 목록에 '인드짜형'이라는 이름만 확인됐고, 어떤 장르·톤인지는 읽히지 않았다.
> 추정 없이 규칙을 지어내지 않는다. 사용자가 아래 「정의 질문」에 답하면 이 파일을 채우고 상태를 `확정` 으로 바꾼다.
> 확정 전에 이 구성을 고르면 스킬은 **`common.md` 만 로드하고 사용자에게 "정의 전 구성"임을 알린다.**

## 정의 질문 (사용자가 채운다)

1. 대상 소스는 무엇인가? (예: 인도 드라마/영화, 인디·독립 영화, 웹드라마 …)
2. 시청자가 얻는 감정은? (통쾌 / 감동 / 웃음 / 긴장 / 기타)
3. 기존 구성 중 가장 가까운 것은? (`drama` / `touching-reversal` / `variety` / 해당 없음)
4. 자막 언어·번역 필요 여부는? (외국어 원본이면 번역 자막 규칙이 추가로 필요)
5. 권장 길이와 나레이션 비중은?

## 채우는 방법

- 3번에서 가까운 구성이 있으면 **그 파일을 상속**하고 차이만 적는다(`drama-first-person.md` 방식).
- 외국어 원본이면 `common.md` §8 에 맞춰 **번역 SRT를 별도 산출물**로 둔다. 번역 오류는 `corrections` 에 남긴다.
