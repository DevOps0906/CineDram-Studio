# 한드짜 — 갈등·반전형 (drama.md)

무시·갑질·괴롭힘이 쌓이다가 뒤집히는 **통쾌형**. 무료판 규칙.md의 구성 규칙을 이어받아 보강했다.
로드: `common.md` + 이 파일.

| 항목 | 값 |
|---|---|
| 총 길이 | 30~55초 (권장 35~50) |
| 나레이션 비중 | 35% 이하 |
| 핵심 긴장 | 갈등 → 쌓임 → 뒤집힘 |
| 제목 틀 | `역할 + 행동 / 궁금증`, `~의 최후`, `~하면 생기는 일` |

## 소재

- **D1-1 MUST** 갈등은 **한쪽이 한쪽을 누르는 구도**여야 한다(무시·막말·갑질·모함). 쌍방 말다툼은 뒤집힘이 약해 제외한다.
- **D1-2 MUST** 뒤집힘이 **원본 화면에** 있어야 한다. 정체 공개, 실력 증명, 증거 제시, 제3자의 개입 중 하나가 눈에 보일 것.
- **D1-3 SHOULD** 뒤집힌 뒤 **비꼬는 한마디**나 상대의 굳은 얼굴이 있는 후보를 우선한다(점수표 '끝 장면 힘' 가산 기준).
- **D1-4 SHOULD** '쌓임' 구간에 **세지는 단계가 최소 2번** 보이는 후보를 고른다(막말 → 더 센 막말 → 행동). 한 번 맞고 바로 뒤집히면 쾌감이 짧다.

## 구성

- **D2-1 MUST** 쌓임:뒤집힘 길이 비율을 대략 **6:4** 로 잡는다. 쌓임이 너무 짧으면 뒤집힘이 가볍고, 너무 길면 이탈한다.
- **D2-2 MUST** 후킹은 **누르는 쪽의 첫 가해 대사** 또는 **당하는 쪽의 첫 반응**에서 연다. 뒤집힘 장면으로 열지 않는다(C3-1).
- **D2-3 SHOULD** 나레이션은 쌓임 구간 앞쪽에 몰고, 뒤집힘 이후에는 원음으로 간다. 뒤집힌 뒤에 설명이 길어지면 쾌감이 식는다.
- **D2-4 SHOULD** 주인공이 **참는 얼굴**(쌓임)과 **돌아서는 얼굴**(전환) 컷을 각각 1개 이상 확보한다.

## 결말

- **D6-1 MUST** 끝 3초 = 펀치 대사 끝음절 + 당한 쪽 얼굴. 사과 장면이 이어져도 **사과 전에 끊는다**(사과·용서는 흐지부지 결말 → C1-6).
- **D6-2 SHOULD** 제목이 `~의 최후` 이면 끝 얼굴이 **무너지거나 굳은 표정**이어야 한다. 단순 침묵은 부족하다.

## 제목 틀 (빈칸을 역할로 채운다)

| 틀 | 예시(가상) |
|---|---|
| 역할 + 가해 / 결과 암시 | `신입 무시하던 부장 / 3초 만에 굳은 이유` |
| 역할 + 의 최후 | `전학생 괴롭히던 반장의 최후` |
| 상황 + 하면 생기는 일 | `정체 숨긴 신입에게 시비 걸면 생기는 일` |
