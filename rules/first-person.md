# 1인칭 나레이션형 (first-person.md)

주인공이 **"나는…"** 으로 상황을 들려주는 형. 시청자가 주인공 시점에 서게 만든다.
로드: `common.md` + 이 파일. **대체:** C5-5(나레이션 35% 상한), C4-3 일부(제목은 1인칭 가능).
한드짜 + 1인칭은 `drama-first-person.md` 가 이 파일을 함께 로드한다.

| 항목 | 값 |
|---|---|
| 총 길이 | 30~55초 |
| 나레이션 비중 | **40~55%** |
| 시점 | 주인공 한 명, 끝까지 고정 |
| 제목 틀 | `나를 ~하던 / ~의 최후`, `내가 ~했더니` |

## 시점·말투

- **F5-1 MUST** 화자는 **한 명**이고 끝까지 바뀌지 않는다. 화자는 원본에서 **화면에 계속 등장하는 인물**이어야 한다.
- **F5-2 MUST** 나레이션은 화자가 **직접 보고 듣고 한 일**만 말한다. 화자가 현장에 없던 장면의 나레이션은 쓰지 않는다(그 장면은 원음으로).
- **F5-3 MUST** 내면 서술("그때 나는 속으로 비웃었다")은 **원작 화면의 표정·행동·대사 근거**가 있을 때만 쓴다. 근거가 없으면 사실 서술로 바꾼다(C5-1).
- **F5-4 MUST** 말투(반말/존댓말, 어미)를 처음 문장에서 정하고 끝까지 유지한다. 화자 성격에 맞게 한다(차분함/냉소/억울함).
- **F5-5 SHOULD** 어미를 섞는다. `~었다`, `~더라`, `~했지`, 명사 끊기를 번갈아. 같은 어미 연속 2회까지(C5-4).

## 구성

- **F2-1 MUST** 후킹 대사 → **"나는" 1인칭 나레이션**으로 이어진다. 첫 문장에서 "누구의 시점인지"가 드러난다.
- **F2-2 MUST** 나레이션과 원음이 **번갈아** 간다. 나레이션만 3컷 연속이면 화면이 설명 영상이 된다. 연속 나레이션 최대 2컷.
- **F2-3 SHOULD** 반격·전환의 순간은 나레이션 없이 원음으로 보낸다(화자가 말로 "나는 반격했다"고 먼저 말하지 않는다).
- **F2-4 SHOULD** 나레이션 문장 한 개에 정보 하나. 2개 이상 담으면 쪼갠다.

## 결말

- **F6-1 MUST** 끝은 여전히 **원작 대사 + 얼굴**(C5-3). 마지막 1인칭 한마디가 필요하면 펀치 **앞**에 둔다.

## 제목 틀

| 틀 | 예시(가상) |
|---|---|
| 나를 + 행동 + 의 최후 | `나를 무시하던 팀장의 최후` |
| 내가 + 행동 + 했더니 | `내가 정체를 밝혔더니` — **결과를 숨기는지 확인** |

## 추가 점검 항목

| # | 항목 | 규칙 |
|---|---|---|
| F-1 | 화자가 한 명이고 화면에 계속 나오나 | F5-1 |
| F-2 | 화자가 모르는 장면의 나레이션이 없나 | F5-2 |
