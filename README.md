# 쇼츠 설계도 (shorts-designer)

원본 영상 + 자막(SRT) → **쇼츠 한 편의 소재·후킹·제목·컷 편집 지시서·자막·나레이션**을 만들어 주는 Claude 스킬 + 규칙 세트.
영상은 만들지 않고 캡컷에서 사람이 자르게 하는 설계도다. 영드짜 무료판을 **"구성 = 규칙 파일 한 벌"** 구조로 확장했다.

핵심 원칙: **구성을 늘릴 때 코드를 바꾸지 않고 규칙 파일만 추가한다.**

## 진행 현황

기준일 2026-11-02. **개발 0·2단계 완료(서버·보안 골격 + 큐 워커)**. 웹 화면 코드는 아직 없고, 엔진(`engine/shortsflow.py`)·로컬 서버(`server/`)·워커(`worker/`)·공용 모듈(`core/`)·SQLite 스키마·테스트가 있다.

## 개발 기획

원본 영상 + 자막(SRT) → 쇼츠 설계도(소재·제목·컷 지시서·자막·나레이션)를 만드는 스킬·규칙 세트를, 운영 화면과 제작 파이프라인이 있는 **쇼츠 제작 스튜디오**로 확장하는 계획이다.

| 영역 | 기획 요약 | 정본 |
|---|---|---|
| 제품·파이프라인 | 권리 게이트 → 구성 선택 → 소재 → 제목 → 컷표 → ★기획 승인(사람) → 제작 → 승인함 → 업로드 게이트(사람) | [docs/00](docs/00-통합설계서.md) |
| 원클릭 제작 | 방식·소재 선택 → 버튼 한 번에 내부 6단계(받아쓰기→대본·제목→장면 맞추기→목소리·자막→자동 검수→렌더), 자동 검수 6가지. 제작 모드 3종(자동제작 기본 / 캡컷으로 편집 / Aside 사용하기) | [docs/13](docs/13-원클릭제작흐름.md) |
| 소재 모드 | 새 소재 / 같은 소재 / 같은 결 다른 소재 / 같은 결 같은 소재·다른 번역본(AI 재번역, en·ja) / 다른 결 | [modes/topic-modes.md](modes/topic-modes.md) |
| 환경설정·대기 큐·채널 | 환경설정 3탭(계정 · AI API · 업로드 방식), 채널 관리(구글 계정 다수 → YouTube 채널 개별 등록), 대기 큐(AI 단계 병렬 / 렌더 직렬) | [docs/14](docs/14-환경설정과대기큐.md) |
| 커리큘럼 반영 | 외부 커리큘럼 1~4주차를 기존 기획과 비교해 흡수·별도 메뉴를 채택, 사이드바 7그룹 | [docs/15](docs/15-커리큘럼반영.md) |
| 디자인 | Tailwind CSS v4.3.3 `@theme` 토큰, 프라이머리 `#2160e0` 확정, 3구간 반응형(~767 / 768~1199 / 1200~) | [design/DESIGN.md](design/DESIGN.md) |

**지키는 규칙(절대)**: 업로드·기획 승인(`approve`)은 사람만 한다. 자동 업로드는 기본 꺼짐이고 own/licensed + 점검 통과 + 채널별 명시적 켬일 때만 허용한다. 권리 미확인 소재는 업로드를 막는다. API 키·OAuth 토큰은 서버에만 저장한다(자세한 규칙: [AGENTS.md](AGENTS.md), [docs/14 §5~6](docs/14-환경설정과대기큐.md)).
