# 15. 외부 강의 커리큘럼(1~4주차) 반영 분석

외부 강의 정규강 커리큘럼(사용자가 만든 것이 아님)을 이 프로그램에 적용했을 때 필요한 기능·메뉴를 정리한 문서다.
**슬라이드 글자는 판독값이라 오독할 수 있고, 슬라이드에도 "상세 커리큘럼은 일부 변동될 수 있습니다"라고 적혀 있다.** 슬라이드의 수익·조회수 수치는 광고 문구라서 요구사항으로 옮기지 않는다.

## 2. 겹치는 묶음 분석 → 채택 (사용자 지시: "비슷한 내용이면 서로 분석해 가장 좋은 방법으로")

새 메뉴를 늘리기 전에 **기존 화면의 탭·섹션으로 흡수**할 수 있는지부터 따졌다. 선택지: A = 기존 화면에 흡수 / B = 별도 메뉴 / C = 섞기.
기준: ① 사용자 흐름 단순성 ② 정답 소스 일원화(같은 데이터를 두 곳에서 편집하지 않음) ③ 보안·권리 게이트 정합(AGENTS.md, 안 A, docs/14 §5~6) ④ 구현 비용·단계 ⑤ 캡처 근거.

| 묶음 | A 흡수 | B 별도 메뉴 | C 섞기 | 채택 · 이유 |
|---|---|---|---|---|
| 채널 관리 ↔ 환경설정 구글 계정·업로드 방식([docs/14](14-환경설정과대기큐.md) S-CH1·S-ST4) | 환경설정 탭에 흡수 + 사이드바 바로가기(이전 채택) | 채널 관리 독립 메뉴(S-CH1)로 계정·채널을 일원화, 환경설정에서는 삭제 ⑤ 캡처의 사이드 메뉴와 일치 | — | **B(사용자 확정 2026-11-02: 두 곳이 겹침).** 계정 연결·채널 등록·제거는 S-CH1에서만, 업로드 방식 선택은 환경설정 S-ST4에 그대로(사용자 결정 ② 유지). 데이터 모델·보안 규칙은 바뀌지 않음 |
| 일일 루틴·원격 승인 ↔ 홈·승인함·대기 큐 | ① 홈 상단 "오늘 할 일 3묶음"(소재 고르기·기획 승인·업로드 승인 대기 수) → 각 게이트로 이동 ② 수치는 jobs 상태에서 계산 | 같은 목록을 또 만듦 | — | **A(홈 섹션).** 게이트는 이미 관문·승인함에 있고, 홈은 모바일 하단 탭 첫 화면([docs/03](03-화면설계.md)). 원격(폰) 접속은 보안 규칙 변경이라 **사용자 확정 대기**(§3) |
| 수정 기억 ↔ 승인함 수정 요청([docs/13 §14](13-원클릭제작흐름.md)) · 타율·기획점([docs/08 §7·§8](08-보관함과성과와타율.md)) | 채널 성적표에 "규칙 후보" 섹션. 데이터 = 수정 요청 이력 | 새 화면 S-MM1 | — | **A(성적표 섹션).** 규칙 후보의 효과는 타율로 판단하므로 같은 화면이 낫다. `rules/` 반영은 사람 승인 |
| 황금키워드 · 소재 선점 · 롱폼 트래픽 ↔ 레이더([docs/12](12-레이더모듈.md), docs/13 STEP 2~5) | 레이더 탭 추가(S-RD5 황금키워드) | 별도 키워드 메뉴 | — | **A(레이더 탭).** 수집 원칙(공식 API·수동, docs/12 §5)을 같이 쓴다 |
| AI 비용 ↔ AI 비용 한도([docs/14 §6-4](14-환경설정과대기큐.md)) · AI 직원 설정([docs/10 §8](10-AI직원구조와저점지표.md)) | 환경설정 AI API 탭(S-ST2)에 사용량·한도 섹션 | 비용 대시보드 S-CO1 | — | **A(S-ST2 섹션).** 키·한도·사용량이 한 화면. `llm_calls` 선행(docs/00 §15 ❌) |
| 저작권 3아웃 방지 ↔ 권리 게이트 R9 · `rights_status` · [docs/05](05-플랫폼정책근거.md) | 업로드 전 점검 = 승인함 카드, 작품 안전 등급 = 작품·레이더 카드 배지, 채널 경고 기록 = 채널 행 | 리스크 센터 S-RK1에 전부 | 점검은 승인함(기존), **기록·집계만** S-RK1 | **C.** 업로드 게이트는 승인함 한 곳(중복 없음). 채널 단위 경고·스트라이크 집계는 기존에 없어 화면이 하나 필요. 법적 단정 금지(R9-3) |
| 프리셋 공유 ↔ `rules/` 구성 파일 | 원클릭 제작 방식 카드에 [내보내기]·[가져오기] | 프리셋 메뉴 S-PR1 | — | **A(카드 액션).** 구성 추가 = 규칙 파일 추가(AGENTS.md). 가져온 규칙은 🔒 검사 후 사람이 활성화 |
| 제작 방식 카테고리(쇼츠/롱폼/기타) ↔ [docs/13 §4](13-원클릭제작흐름.md) | S-OC1 카드에 탭 | — | — | **A.** 28개 중 12개만 확인 상태 유지, 롱폼 3개는 이름 `미확인` → 규칙 파일 필요 |
| 성과·수익(쇼핑 수익 자동, 광고 수익) | — | — | — | **범위 밖.** 성과 수집은 docs/08 §6 범위만 |

결과: 별도 메뉴 화면은 **S-RK1 리스크 기록**과 **S-CH1 채널 관리**(환경설정 구글 계정 탭을 옮김, 신규 기능 아님) 두 개다. 나머지는 기존 화면의 탭·섹션·액션이다.
