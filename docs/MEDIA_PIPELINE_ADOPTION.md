# 미디어 파이프라인 적용 메모 (WhisperX · HyperFrames)

작성일 2026-11-20. 상태: **제안**. 공용 기획 정본: `platform-docs:products/_platform-core/MEDIA_PIPELINE.md`. 코드는 바꾸지 않았다.

## 현황

| 항목 | 내용 | 근거 |
|---|---|---|
| STT | faster-whisper medium(GPU) 또는 small(CPU)로 SRT 생성 | `skills/shorts-blueprint/SKILL.md:71` |
| 최종 편집 | 영상은 만들지 않고 캡컷에서 사람이 자르는 설계도 | `README.md:4` |
| 미리보기 | ffmpeg로 선택 생성 | `README.md` 진행 현황 |

## 적용안

| ID | 내용 | 영향 | 선행 |
|---|---|---|---|
| C-1 | SRT 생성 단계에 WhisperX 정렬을 옵션으로 비교해 컷 시각 오차를 줄일 수 있는지 평가 | STT 단계 | 스파이크 S1 |
| C-2 | 캡컷 수작업 구간(컷·자막)을 FFmpeg로 최종본까지 자동화할 수 있는지 범위 평가. 자막 모션은 HyperFrames 후보 | 제품 범위 | S1, S2 |

주의: 이 제품의 정체성은 "사람이 캡컷에서 마무리하는 설계도"다. C-2는 범위 확장이므로 승인 없이 진행하지 않는다.
