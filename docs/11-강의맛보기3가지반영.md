# 11. 강의 "맛보기 3가지" 반영 (기획 전략)

사용자가 전달한 강의 슬라이드 요약(천상계영드 3기)을 기존 기획에 녹인 문서다.
**제외:** LTX 영상 생성, ComfyUI, 별도 영상 생성 플랫폼(ShortFlow) 관련 내용은 반영하지 않았다(사용자 요청).
**주의:** 전달된 내용은 슬라이드 요약이며 내가 원본 슬라이드를 직접 본 것이 아니다. 효과 주장은 **가설**이고 우리 성과 데이터로 검증한다(docs/08).

## 1. 강의 → 우리 규칙 매핑

| 강의 | 핵심 | 반영 위치 |
|---|---|---|
| **맛보기 1** 터지는 이야기에는 갈등이 있다 | 누명·오해 / 들킬 위기 / 선택의 기로. 갈등이 없으면 끝까지 볼 이유가 없다 | `common.md` §1 **갈등 3유형**(후킹을 여는 지점, 끝에 보여야 할 것), C1-1, `topic-modes.md` 결 태그 3종 추가 |
| **맛보기 2** 제목에는 정답을 넣지 않는다 | «누명을 벗은 신입 사원»(정답 노출) ↔ «신입이 끝까지 웃고 있던 이유»(정답 숨김) | `common.md` C4-1 에 예시, 제목·오프닝 훅이 함께 궁금증 유발(C3-1) |
| **맛보기 3** 잘 터지는 소재 | 신작(신선) / 명작(알고도 또 먹는 맛) / 스타(이름만으로 멈춤) | `common.md` §1 **소재 매력 태그**, `meta.plan.appeal`, 작품·매력별 타율(docs/08) |
| 작품 선정 + AI 활용 | 영화·드라마·예능의 갈등 구조를 AI로 분석해 숏폼의 결에 맞게 재가공 | 스킬 1단계(분석 결과는 사람이 확인, 지어내지 않기 R9-5), C1-3 |

## 2. 기존 규칙과의 관계

- **이미 있던 것:** 갈등 필수(C1-1), 결과 숨기기(C4-1), 후킹(C3), 결 태그. 강의 내용은 이를 **유형화**하고 **기록 항목**으로 만든 것이다.
- **새로 생긴 것:** 갈등 유형 3종(주 유형 기록), 소재 매력 3종(참고 태그), 기획 승인 시 두 항목 기록(엔진 `approve` 가 미기록이면 경고).
- **충돌 지점 정리:** 선택의 기로는 "한쪽이 누르는 구도"가 아니므로 `drama.md` D1-1 을 적용하지 않고 "선택지 2개가 화면·대사로 보이고, 고른 결과가 나온다"를 점검한다. 들킬 위기는 예고한 결말을 반드시 보여 준다(C6-4).

## 3. 기획점으로 측정 (docs/08 §7 에 추가됨)

| 기획점 | 비교 방법 |
|---|---|
| 갈등 유형 3종 | 유형별 7일 타율·저점 |
| 소재 매력(신작/명작/스타) | 매력별 타율, 작품별 집중도와 함께 |
| 정답 숨긴 제목 | 같은 소재 제목 2종 A/B |

표본 10편 미만이면 결론을 보류한다. 강의의 효과 주장은 목표가 아니라 검증 대상이다.

## 4. 반영하지 않은 것

- LTX/ComfyUI 기반 영상 생성, 프롬프트 인핸서, 멀티샷 자동 생성, 갈등 템플릿 선택 UI를 가진 플랫폼 기능 — 사용자 요청으로 제외.
- 우리 파이프라인은 **원본 영상 + 자막 → 컷 설계** 구조이며, 영상 생성 모델은 쓰지 않는다.

## 5. 엔진·스킬 변경

- `meta.plan.conflict_type`, `meta.plan.appeal` 필드 추가(없으면 `approve` 에서 **경고**, 막지는 않음).
- `기획서.md` 에 갈등 유형·소재 매력 표시.
- 점검표 28번 추가(갈등 유형·매력 기록, 제목 정답 비노출).
